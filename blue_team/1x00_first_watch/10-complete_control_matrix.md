# MedDefense Health Systems: Complete Control Matrix

**Prepared by:** Aïda Sylla, Security Analyst **Prepared for:** James Chen, Deputy CISO (for Board presentation, single authoritative reference) **Source material:** Control Inventory (Task 4), Physical Walk-Through (Task 3), Compensating Control Strategy (Task 6), Control Gap Analysis (Task 5), Asset Registry (Task 7), Criticality Assessment (Task 8), all incident findings (Tasks 1–2) **Purpose:** Consolidate every security control identified across the entire project, implemented and proposed, into one authoritative document, rate each control's real-world effectiveness, and map coverage against MedDefense's Top 5 Critical Assets.

**Important framing for the Board:** This document distinguishes clearly between controls that **exist today** and controls that have been **proposed but not yet implemented** (the MRI compensating strategy from Task 6). Presenting a proposal as an existing protection would misrepresent MedDefense's actual current posture — the two are kept in separate tables throughout.

## Part 2: Updated Control Summary Matrix

This matrix reflects only the **17 implemented controls (C-001–C-017)**, since it represents MedDefense's current, real posture. Effectiveness is scored numerically for averaging (Strong = 3, Adequate = 2, Weak = 1) and the resulting average is shown alongside its nearest qualitative label.

| Category \ Function | Preventive                                                                     | Detective                                                                   | Corrective                             | Compensating         | Deterrent            |
| ------------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------- | -------------------------------------- | -------------------- | -------------------- |
| **Technical**       | 6 controls (C-001, C-002, C-004, C-005, C-008, C-009) - avg 2.0 / **Adequate** | 5 controls (C-003, C-006, C-014, C-015, C-016) - avg 1.2 / **Weak-leaning** | 1 control (C-010) - avg 1.0 / **Weak** | 0 controls - **gap** | 0 controls - **gap** |
| **Administrative**  | 2 controls (C-007, C-013) - avg 1.5 / **Weak-to-Adequate (borderline)**        | 0 controls - **gap**                                                        | 0 controls - **gap**                   | 0 controls - **gap** | 0 controls - **gap** |
| **Physical**        | 2 controls (C-011, C-017) - avg 1.0 / **Weak**                                 | 1 control (C-012) - avg 1.0 / **Weak**                                      | 0 controls - **gap**                   | 0 controls - **gap** | 0 controls - **gap** |

**Reading this matrix:** MedDefense has meaningful _breadth_ of Technical Preventive controls (the highest average of any populated cell), but every Detective cell across all 3 categories averages at or near "Weak", consistent with Gap G-001 (no centralized alerting) identified in Task 5. Corrective, Compensating, and Deterrent functions remain almost entirely empty across the board. The same structural finding from Task 5 still holds after this full consolidation. If the 4 proposed MRI controls (P-001–P-004) are implemented, they would populate the Technical Compensating, Physical Compensating, and Administrative Compensating cells for the first time (but only for the MRI asset specifically, not organization-wide).

**Summary observation for the Board:** Of the five most critical assets in the organization, only one (the EHR System) has meaningful coverage across more than one control function, and even that coverage has real, documented weaknesses. 2 assets, the infusion pumps and the MRI, currently have **no effective control coverage at all**. This Control Coverage Map should be read as the direct, evidence-based justification for prioritizing remediation on exactly these five assets in any resourcing or budget discussion that follows this assessment.
