MedDefense Health Systems: Vulnerability Assessment (The Weak Links)

The technical companion to the Security Posture Assessment (0x00) and the Threat Landscape Report (1x01): where those projects answered "what do we have and where are we weak" and "who is trying to hurt us," this project answers "which specific, exploitable vulnerabilities are actually present, and in what order should they be fixed." Starting from a raw third-party vulnerability scan (31 findings across 47 hosts), it investigates each finding against real sources (NVD, CVSS, CWE, Exploit-DB, CISA KEV), runs hands-on security auditing, and produces a prioritized, threat-informed, business-contextualized remediation and validation plan. Every finding connected back to a specific asset, actor, and gap from the prior 2 projects.

See `0-first_impressions.md` through `23-validation_plan.md` for the full deliverable set.
